THE DAILY GLOBE — one image that sums up the world's news of Friday 20 November 2026: 13 stories and 4 in-brief items across 6 continents, drawn as a single 1024×1024 newspaper front page. Lead: Cyclone Akvan slams into India's east coast. The image is drawn offline by `tools/build_image.py` from the checked stories in `tools/stories.json` and shipped as `entry.png`; `main.py` copies it to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
